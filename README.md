# homebrew-tap

Homebrew formulae and casks for [doruchiulan](https://github.com/doruchiulan)'s tools.

```
brew install doruchiulan/tap/<formula>
brew install --cask doruchiulan/tap/<cask>
```

| Formula | |
|---|---|
| [`anyrec`](https://github.com/doruchiulan/anyrec) | Records any window or display on macOS as separate video, system audio and microphone tracks. |

| Cask | |
|---|---|
| [`anyrec-app`](https://github.com/doruchiulan/anyrec) | The same recorder as a menu bar app. |
